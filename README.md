# Maria Granados | Portfolio

Jekyll portfolio for Maria Granados, Senior AI/ML Engineer.

## Public case-study policy

Architecture visuals are recreated, high-level, and labelled as sanitised architecture. Confidential implementation details and unpublished measures are omitted.

## Local development

This site uses Jekyll and is hosted with GitHub Pages.

```bash
bundle install
bundle exec jekyll serve
```

Main content lives in `index.md`, the case-study Markdown files, and `cv.md`. The visual system is in `assets/css/custom-styles.css`.
